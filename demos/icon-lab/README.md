# Iconflow 个人演示版

一个本地优先的图标规范与动效工作台。亮暗主题不改变资产颜色。

## 当前视觉版本

恢复侧栏与三栏工作台，采用黑白主色、浅灰背景，支持亮暗切换。取消首页式简介与功能卡片。保留上传、规范编辑、候选、动效、资产和导出。候选缩略图随规范参数同步更新。

## 运行

在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173 。需要 HTTP 服务加载本地 JavaScript 模块，不能直接双击 HTML。

## 当前可用

- 单色线性 SVG 上传与安全处理；读取 viewBox、描边、端点和连接参数。
- 参数编辑、实际尺寸预览、代码查看、图标本地保存。
- 明确标注的内置几何模板候选。
- Morphicons 路径匹配与旋转对齐；选择或上传两个状态、拖动进度、正反交替播放、交换、弹簧节奏。
- 图标库：50 个基础图标，支持搜索、下载及选作起始 / 目标图标。
- 状态切换：SVG / PNG 双素材转场，支持点击回弹、缩放、旋转、淡入淡出、滑动五种形式。
- 静态 SVG、PNG、GIF、声明式动画 SVG、Lottie JSON 导出。
- 项目资产点击图标原位播放，正反交替；右上角更多菜单提供编辑与删除。
- 项目备份下载。

## 边界

- AI 尚未接入。自由描述不能生成任意图标；示例候选不是 AI 结果。
- WebP 编码尚未接入，下载入口禁用。GIF 支持白底 / 透明底，透明模式使用二值透明度。
- 上传不支持 transform、滤镜、外部资源、文字、填充图标变形和超过 1MB 的文件。
- 状态切换对完整素材执行转场；图标变形独立使用 Morphicons，需兼容的线性 SVG。
- Lottie 使用折线关键帧，数据量可能较大；各目标播放器兼容性需进一步验证。
- 文件只在本地浏览器处理；数据使用 localStorage，不跨设备同步。备份恢复入口仍待实现。
- 内置用户提供的收藏前后 SVG 作为本地演示样例。

## 演示优化
顶部「一键演示 / 重置」载入模型案例及收藏状态对，保留已保存资产；当前工作台的参考样本与参数会重置。模型、蓝色面形文件、钥匙各有三个独立候选。面形候选隐藏描边设置，颜色同时用于预览、缩略图、SVG 和 PNG 导出。
双击「启动ICONLAB.command」启动本地预览。需已安装 Python 3，运行时保留终端窗口。端口占用会提示，不会终止其他程序。
含渐变、蒙版、裁剪的状态素材暂不支持 Lottie，导出时明确报错，建议选择 GIF / PNG / SVG。
