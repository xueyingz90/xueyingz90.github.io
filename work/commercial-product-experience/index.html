SKU 改版营销视觉

PROJECT OVERVIEW01 / 06

从营销表达到体验减负

{ 从营销吸引到购买决策 }

会员购买页面既承担营销推广，也需要帮助用户理解权益、比较价格并完成购买。随着会员类型和营销内容增加，核心购买信息逐渐被分散。本次改版围绕购买任务重组信息架构，在保留必要商业表达的同时降低干扰。

C端产品 / 商业化体验 / UI/UX Design / Visual Design

我的职责

会员 SKU 视觉与信息层级优化、页面结构及核心模块改版、商品卡片与会员身份、权益视觉及相关营销设计。

PROBLEM / COMPETING ATTENTION02 / 06

{ 当营销信息与购买任务竞争注意力 }

原有首屏以大面积营销资源位为视觉中心。高饱和色彩、活动信息与利益点适合营销传播，但在购买场景中容易与核心任务争夺注意力。

营销信息占据首屏

大面积营销资源位压缩核心商品展示空间。

会员身份感知不足

会员身份与状态不够突出，缺少清晰识别入口。

商品与权益分散

商品、权益与支付信息的层级不够清晰。

视觉竞争明显

高饱和营销、商品卡片与活动标签同时争夺注意力。

STRATEGY / INFORMATION HIERARCHY03 / 06

{ 基于购买任务重塑信息层级 }

营销降噪 × 信息聚焦 × 视觉减负。根据用户理解身份、比较商品与完成选择的任务，重新分配页面信息权重。

营销降噪

压缩营销资源位占比，减少高饱和元素的干扰，从强曝光转向适度表达。

信息聚焦

突出会员身份、价格、权益与支付等核心购买信息。

视觉减负

统一卡片、控制色彩权重，优化文字层级与间距。

会员身份→商品与价格→支付行动→权益说明

SOLUTION / VISUAL REORGANIZATION04 / 06

{ 让会员选择与购买更加直观 }

通过会员身份前置、营销资源位轻量化、商品卡片重构、支付信息聚焦与权益精简，让视觉表达服务于购买决策。

01 会员身份前置

在顶部整合用户名称与会员状态。

02 营销资源位轻量化

保留必要活动信息，将首屏空间交还给商品。

03 商品卡片重构

突出会员类型、价格与优惠。

04 支付信息聚焦

关联购买行动点与实际支付金额。

05 权益信息精简

调整权益介绍与对比方式，降低长页面密度。

OLD / NEW05 / 06

{ 从视觉吸引到信息清晰 }

本次改版并非单纯减少视觉元素，而是根据会员购买场景重新分配信息权重，让营销内容服务于购买任务，使用户更清晰地识别身份、理解商品并完成选择。

旧版｜营销优先

营销资源位与促销信息较为集中，核心商品与身份信息的优先级不足，权益内容分散。

新版｜购买任务优先

会员身份前置、营销轻量化，商品价格与权益更加聚焦，页面语言统一，购买信息更紧凑。

约 5.5 屏 → 约 3 屏

页面长度的客观改版信息；不代表转化、留存或效率提升的验证结果。

VISUAL EXTENSION06 / 06

{ 视觉延展｜不同场景下的设计表达 }

营销视觉侧重视觉吸引力、活动氛围与利益点传播；产品体验关注信息理解、任务效率与操作清晰度。以下保留原有营销素材，具体内容与排版待继续调整。
