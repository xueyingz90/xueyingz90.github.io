DISPLAY CONSTRAINTS / VISUAL LANGUAGE02 / 08

{ 视觉语言探索：在显示限制中建立情绪感知 }

当显示能力有限、真实环境持续变化时，情感化设计需要依靠更轻量的视觉语言。

现实限制

01 单色显示

有限的色彩表达难以直接依靠丰富颜色建立情绪。

02 透明背景

虚拟视觉需要与真实环境共存，不能过度干扰用户视野。

03 小尺寸视野

复杂图形和过多信息容易造成识别负担。

设计策略

Brightness / 光影

利用明暗变化建立视觉层级与状态反馈。

Particle / 粒子

通过聚散、数量与密度变化强化生命感和空间感。

Motion / 轨迹

利用运动路径建立方向感，引导用户理解视觉变化。

设计结论

在有限显示能力下，情绪表达不必依赖复杂视觉，而可以来自出现方式、变化节奏与空间关系。

GAZE INTERACTION / CONCEPT05 / 08

{ 从被动观看，到主动参与 }

探索将自然注视行为转化为交互输入，让用户通过视线参与生日仪式。

交互预研 · 不代表已完成眼动识别或技术验收

  1. 01

    发现目标 / Discover

    →
  2. 02

    视线跟随 / Follow

    →
  3. 03

    完成触发 / Complete

    →
  4. 04

    情绪回应 / Reward

交互概念

用户注视轨道中的小行星，通过视线跟随完成一圈运动，触发数字变化与视觉回应。

交互流程

01 发现目标 / Discover

小行星出现在轨道中，引导用户注意。

02 视线跟随 / Follow

用户通过注视和视线移动参与轨道探索。

03 完成触发 / Complete

当满足预设的注视完成条件时，触发反馈。

04 情绪回应 / Reward

数字增加，配合视觉变化形成参与后的反馈。

设计决策

让交互目标自然出现

将可注视对象融入原有星球场景，而非增加独立操作控件。

让参与过程可感知

通过轨迹变化和动态反馈，帮助用户理解交互进度。

让完成动作获得回应

将数字变化与生日视觉结合，让交互结果成为仪式的一部分。

MONOCHROME × FULL COLOR06 / 08

{ 同一种情绪，两种显示语言 }

针对不同显示条件，探索如何通过不同视觉语言传达相同的生日情绪。

Monochrome / 单色方案

在有限色彩和显示空间中，通过光影、粒子与轨迹建立情绪感知。简洁符号，低干扰反馈。

Full Color / 全彩方案

利用色彩、材质和空间层次建立更丰富的生日叙事，探索交互式视觉回应。

两种方案是针对显示能力的体验表达探索，不是简单换色。
